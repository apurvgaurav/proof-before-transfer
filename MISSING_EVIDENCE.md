# Available evidence and reproduction limits

This release preserves the available scientific records and states which parts of the historical experiment cannot be reconstructed from them. It does not claim a complete capture-to-result reproduction.

| Record or claim | What is available | Remaining limit |
| --- | --- | --- |
| Original classical model and predictions | Five CBM models, freeze records with Platt coefficients, saved qualification probabilities, scores, labels, and family assignments | The supported verifier uses saved qualification probabilities. It does not rerun main-model qualification inference. |
| Historical calibration | The 64 retained DEV-CAL rows, exact fitted sigmoid parameters and a later 320-row margin audit across five seeds | The original calibration-time per-unit margin log and complete fit log are unavailable. The retrospective margin file is not such a log. Original joblib containers are intentionally omitted; coefficient JSON records are included. |
| Nuisance control | Saved nuisance probabilities, nine-field metadata, training labels, qualification labels and the recorded original control result | The exact frozen `C6_R2_NUISANCE_EVALUATOR_v3.py` and fitted nuisance artifact are unavailable. Its recorded SHA-256 is `4220b861e2a2c5721529a87e877555a062e216f17ca5eb6f4b8ad4c672043062`. No different evaluator is substituted. The R4 nuisance materializer is source for metadata preparation, not that missing evaluator. |
| Qualification partitions | The final R5 semantic units, feature rows and schedule, plus the retained R3 TRAIN/DEV roles | The final R5 construction/split source and a complete regeneration record are unavailable. The verifier checks stored assignments, not an independently reconstructed R5 partition process. |
| Reconciliation | Retained reconciliation and auxiliary indexes; a documented public derivative of the row/PCAP index | The full original reconciliation archive and underlying qualification row/capture archives are unavailable. The recorded full-archive SHA is `9ca63c903fb1c46d5e71e443f11595a6578ff1f4ec098af9469beaf55477af03`. An index hash or list of capture hashes does not verify absent capture bytes. |
| Qualification/adjudication archive | Selected exact scientific members from the recovered original P7/P8 archive, identified by SHA `d887ce8d33c56da23d77ee40305c9ed88a6e5268b7253c016dc796656f45d852` | That P7/P8 archive is distinct from the missing reconciliation archive. The complete original container is not bundled; selected members have explicit provenance. |
| Runtime | Retained Go source, a hash-referenced summary of R4 sentinel records, and implementation identifiers | Records support one R4 sentinel with four requests and a Go 1.26.6 client. The final R3 and R5 client/server identifiers differ from that R4 sentinel. A complete source-to-executable-to-capture binding for the final R3/R5 collections is unavailable. See `provenance/runtime_provenance.json`. |
| Scientific executors | Exact P7 and P8 Python blocks extracted from the preserved R5 runner, and retained evaluation/training/feature source | The operational deployment wrapper is omitted. The P7 block still depends on historical bindings and the missing exact nuisance evaluator. Not every historical executor or environment dependency is included. |
| Retrospective diagnostics | Ten fitted numeric baseline models, a training-prior baseline, and a stored record-token lookup; their saved coefficients, predictions and results | These checks examine shortcuts in the existing task. No new independent, harder qualification task is included. No representation-ablation study is claimed by this release. |
| Transfer and external validity | A qualification protocol and results for synthetic classical-regime data | No X25519-to-X25519MLKEM768 transfer experiment, production-traffic validation, or empirical post-quantum transfer effect is reported. |

The public release includes original scientific data and explicitly identified derivatives. The locator-index transformation removes absolute local path prefixes while retaining archive basenames and scientific fields. The baseline protocol derivative removes one administrative mapping field; the scientific protocol is unchanged. Both transformations record original and public hashes.

The retained source uses some historical generic workstation paths and isolated-testbed addresses. Those values have been preserved to maintain source identities. Synthetic request paths are part of the experimental data and have not been rewritten.
