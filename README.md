# Proof Before Transfer

Companion repository for my paper, **Proof Before Transfer: Leakage-Resistant Qualification for Post-Quantum TLS Intrusion-Detection Studies**.

## About the study

I examined the checks needed before interpreting changes in intrusion-detection performance when moving from classical to post-quantum TLS. The study covered classical-regime qualification on synthetic traffic, followed by retrospective checks for traffic-length shortcuts.

The X25519-to-X25519MLKEM768 transfer experiment was not run. The paper reports the qualification procedure and the limitations identified during revision.
